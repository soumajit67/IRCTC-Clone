This project is an IRCTC Clone, a responsive front-end web application designed to replicate the core functionality and user experience of the official Indian Railway Catering and Tourism Corporation website. The main goal of the project is to practice modern web design principles while creating a visually appealing and fully functional train ticket booking interface that works seamlessly across mobile phones, tablets, laptops, and desktop screens.

The application is built using only HTML5 and CSS3, with a focus on clean semantic markup and modern styling techniques. The interface uses the Inter typeface from Google Fonts to ensure readability and a contemporary look. A CSS variables system defines the color palette, spacing, shadows, and transitions, making the design consistent and easy to maintain. The primary color scheme uses a professional blue for branding and an energetic orange for calls to action, which improves visual hierarchy and guides user attention to important elements like the login and search buttons.

The layout starts with a fixed navigation bar that includes the IRCTC Clone logo, menu links for Home, PNR Status, Trains, and Contact, and a prominent Login button. On smaller screens the navigation automatically converts into a hamburger menu using a pure CSS toggle, which keeps the interface uncluttered on mobile devices without requiring JavaScript. Below the navbar is a full-height hero section featuring a high-quality train background image with a gradient overlay. This section uses CSS Grid to create a two-column layout on larger screens, placing marketing text on the left and the booking form on the right, then stacks into a single column on tablets and phones.

The booking form is the central component of the project. It includes tabbed navigation for Book Ticket and PNR Enquiry, input fields for source and destination stations with a swap button, date picker, class selection, and quota dropdown. Each input is wrapped with descriptive labels to improve accessibility. Checkboxes for Flexible with Date and Divyaang Concession are styled with custom accents. The search button uses a gradient background and subtle hover animation to provide interactive feedback. All form elements have focus states and smooth transitions to enhance usability.

Responsiveness is handled through three major breakpoints. For screens below 1024px the grid collapses to one column and the hero text centers. Below 768px the hamburger menu activates, form fields stack vertically, and the swap button rotates for better touch ergonomics. Below 480px padding and font sizes reduce to fit small screens while maintaining tap targets of at least 48px for accessibility. Additional sections include a three-card features area highlighting Secure Booking, Instant Confirmation, and Mobile Friendly benefits, and a footer with links and copyright information.

Overall this project demonstrates proficiency in responsive layout design, CSS architecture, accessibility considerations, and user-centered styling. It serves as a strong foundation that can be extended with JavaScript for live search, API integration for real train data, form validation, and dark mode support in future iterations.
